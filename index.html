独立开发 · 2026.07 — 至今 · v0.1.4 已发布

N-Link

尼康相机「永不断联」伴侣 App（Android）

官方 SnapBridge 频繁断联没人在意，我拆了它的四类根因，自己做了一个稳的。

  • 问题定义拆解竞品四类根因：频繁断联 / 后台被杀 / Wi-Fi 切换脆弱 / 无自动重连，确立「稳、快、全、简」的差异化定位与功能边界。
  • 核心实现BLE 发现 + Wi-Fi 高速传输 + USB 有线的多通道连接调度与断线自动重连；基于 PTP/USB 协议完成相机参数读写与遥控拍摄（半按对焦 / 全按 / 间隔 / B 门）。
  • 功能交付拍完即传、选择性下载、Live View 监看与触摸对焦、参数管理四大模块；40+ 能力项按 P0/P1/P2 排期，8 周交付 MVP。
  • 质量与迭代定义并持续跟踪 24h 连接保持率、传输成功率、Live View 延迟、快门响应四项核心指标，制定四阶段 Roadmap 按指标验收。
